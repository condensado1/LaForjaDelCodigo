# Checklist de seguridad

Antes de entregar, verifica:

- [ ] No subí archivos `.env` ni secretos.
- [ ] Tengo un `.gitignore` adecuado para mi stack.
- [ ] No hardcodeé claves, tokens o credenciales en el código.
- [ ] Si subí algo sensible por error, revisé historial de commits antes de hacer push y lo removí correctamente.
