# LaForjaDelCodigo
La Forja del Código es un evento privado donde juniors nos retamos a construir mini proyectos en rondas de 1 a 4 semanas, según la complejidad del tema. Cada ronda tiene su propia tecnología, requisitos y objetivos. No se trata de tener software terminado ni perfecto. Se trata documentar el proceso y aprender de lo que hicieron los demás.
